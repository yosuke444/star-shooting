# STAR SHOOTING

ドット絵見下ろし型シューティングバトロワ(HTML / JavaScript、外部画像・音声ファイルなし)

## 遊び方

- `index.html` をブラウザ(PC の Chrome / Edge / Firefox 推奨)で開くだけで CPU 戦が遊べます。
- フレンド戦はインターネット接続が必要です(後述)。

### 操作
| キー | 動作 |
|---|---|
| 矢印キー | 移動 / 向きを変える(Z なしだと撃たずにゆっくり移動) |
| Z(押しっぱなし) | アクセル + ショット連射 |
| X | マシンの近く → 乗り換え / それ以外 → アイテム使用 / 観戦中 → 観戦相手の切り替え |
| X 長押し | アイテムスロットの入れ替え |
| M | ミュート |
| Esc | ポーズ(CPU 戦・ホスト) / 切断(参加者) |

ゲーム中のボタンは Z と X だけです。M と Esc はゲーム外の補助用です。

## 試合の流れ
1. **トレーニング**(1〜10 分、ホストが設定。デフォルト 3 分)
   - 雑魚敵を倒すとステータスアイテム、宝箱はラストアタックした人が中身を総取り
   - マップに落ちているマシンに X で乗り換え → 乗っていた時間に応じてステータスボーナス + 全回復
   - イベントが時間に応じて数回発生
2. **ステージルーレット** → 5 種類の闘技場から 1 つを抽選
3. **バトル**: 全員全回復、安全地帯が狭まっていく中で最後の 1 人まで

## フレンド戦(端末同士の直接接続)
- WebRTC(PeerJS)で端末同士を直接つなぎます。ホストの端末がゲームを計算し、参加者は入力を送って画面を受け取ります。
- 最初の接続の仲介だけ PeerJS の公開シグナリングサーバー(0.peerjs.com)を使います。ゲーム中のデータは端末間で直接やりとりします。
- ホストが「ルームを作る」→ 表示された 5 文字のコードを参加者が「ルームに参加」で入力。足りない人数は CPU が埋めます。
- 途中で切断した参加者は CPU に切り替わります。
- 中継(TURN)サーバーは使っていないため、会社や学校のネットワーク・一部のモバイル回線など、ネットワーク環境によっては直接接続できないことがあります。

## 軽量化・ラグ対策
- 粒子はすべて 1 つの型付き配列プールで一括更新・描画(画面外の演出は生成しない)
- 世界は 480×270 の低解像度バッファに描いて 2 倍拡大、UI だけ 960×540 でくっきり描画
- 描画キャンバスは 960×540 固定。ウィンドウに合わせて縦横比を保ったまま拡大縮小(引き伸ばし無し)
- 当たり判定は空間グリッドで近くのものだけ判定
- 通信は 20Hz のスナップショット。各参加者には自分の周囲のものだけ送り、数値は整数の配列に圧縮
- 参加者側は自機の動きを先読み(予測)し、他の物体は補間して滑らかに表示
